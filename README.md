"Smart Career Recommendation System".

The project is an AI-powered career guidance platform built using:

Python
Flask
scikit-learn
spaCy
NLTK
MongoDB
HTML
CSS
JavaScript

Project features:

- AI career prediction using machine learning models
- Ensemble ML model (Decision Tree, KNN, Random Forest)
- NLP-based resume analysis for skill extraction
- Career assessment quiz
- Job explorer using APIs
- Interview preparation module
- Personalized career roadmap
- User authentication system
