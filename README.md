# 🚀 Smart Career Recommendation System

An **AI-powered career guidance platform** that analyzes user skills, interests, and academic background to recommend suitable career paths using **Machine Learning and NLP**.

This platform helps students and job seekers discover the best career options and improve their skills through personalized insights.

---

## ✨ Features

🔹 AI-powered career prediction  
🔹 Career assessment quiz  
🔹 Resume analysis using NLP  
🔹 Real-time job exploration  
🔹 Interview preparation module  
🔹 Personalized career roadmap  
🔹 User authentication and dashboard  

---

## 🧠 Machine Learning Model

The platform uses an **ensemble machine learning approach** combining multiple models:

- Decision Tree
- K-Nearest Neighbors (KNN)
- Random Forest

These models work together using a **voting classifier** to improve prediction accuracy.

## ⚙️ Installation

Clone the repository:

git clone https://github.com/WhiteHAT-Prakash/career-ai-recommendation-system.git

Go to project directory:

cd career-ai-recommendation-system

Install dependencies:

pip install -r requirements.txt

Run the application:

python app.py
